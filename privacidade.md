# Política de Privacidade — Hermes Agent

Última atualização: 08/11/2026

O Hermes Agent é um aplicativo de uso pessoal e exclusivo de Rodolfo Vinicius (rodolfovinicius@gmail.com). Ele não é oferecido ao público e não possui outros usuários.

## Dados acessados

Com a autorização do próprio titular da conta, o aplicativo acessa dados das APIs do Google (Gmail, Google Agenda, Google Drive, Contatos, Planilhas, Documentos e Google Tarefas) somente para automatizar tarefas pessoais e profissionais do titular, como organizar tarefas, ler anexos e consultar a agenda.

## Uso e armazenamento

Os dados são processados localmente no computador do titular. O token de acesso fica armazenado apenas nesse computador. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.

## Uso de dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google (https://developers.google.com/terms/api-services-user-data-policy), incluindo os requisitos de Uso Limitado.

## Revogação

O acesso pode ser revogado a qualquer momento em https://myaccount.google.com/permissions.
